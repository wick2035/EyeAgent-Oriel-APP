E2EE 医生列表 API（前端对接文档）                     
                                                          
  1. 基本信息                                           
                                                          
  ┌──────────┬────────────────────────────────────────┐
  │    项    │                   值                   │   
  ├──────────┼────────────────────────────────────────┤ 
  │ 用途     │ 获取已开通 E2EE 加密聊天服务的医生列表 │   
  │          │ （用于"在线咨询"页面卡片渲染）         │ 
  ├──────────┼────────────────────────────────────────┤   
  │ URL      │ GET /api/app/chat/keys/e2ee-doctors    │ 
  ├──────────┼────────────────────────────────────────┤   
  │ 鉴权     │ 需登录（请求头携带 satoken）           │
  ├──────────┼────────────────────────────────────────┤   
  │ Content- │ application/json                       │ 
  │ Type     │                                        │
  ├──────────┼────────────────────────────────────────┤   
  │ 分页     │ 支持，基于 page/size Query 参数        │
  └──────────┴────────────────────────────────────────┘   
                                                        
  ---                                                     
  2. 请求                                               
                                               
  Query 参数                                              
                            
  ┌──────┬──────┬──────┬──────┬────────────────────────┐  
  │ 参数 │ 类型 │ 必填 │ 默认 │          说明          │
  ├──────┼──────┼──────┼──────┼────────────────────────┤
  │ page │ int  │ 否   │ 1    │ 页码，从 1 开始        │
  ├──────┼──────┼──────┼──────┼────────────────────────┤  
  │      │      │      │      │ 每页条数，范围 [1,     │
  │ size │ int  │ 否   │ 5    │ 100]，超出会被服务端   │  
  │      │      │      │      │ clamp                  │
  └──────┴──────┴──────┴──────┴────────────────────────┘
                                                          
  请求头                                    
                                                          
  ┌─────────┬────────────────────────────────────┐      
  │ Header  │                说明                │        
  ├─────────┼────────────────────────────────────┤
  │ satoken │ 登录态 Token（患者或医生登录均可） │        
  └─────────┴────────────────────────────────────┘      
                                               
  示例                       
                                                          
  GET /api/app/chat/keys/e2ee-doctors?page=1&size=5
  HTTP/1.1                                                
  Host: <host>                                          
  satoken: eyXXXXXX...                         
                                                          
  ---

  DoctorCard 对象字段                                     
                                                        
  字段: doctorId                                        
  类型: string                                          
  可空: 否                                              
  说明: 医生唯一 ID                                     
  卡片对应位置: 详情跳转参数                            
  ────────────────────────────────────────                
  字段: name                                            
  类型: string                                            
  可空: 否                                              
  说明: 医生姓名                                          
  卡片对应位置: 卡片标题                                
  ────────────────────────────────────────             
  字段: title                                             
  类型: string                                         
  可空: 是                                                
  说明: 职称（如"主任医师" / "副主任医师"）             
  卡片对应位置: 姓名下方                                  
  ────────────────────────────────────────              
  字段: avatarUrl                                         
  类型: string                                          
  可空: 是                                             
  说明: 头像 URL，完整可访问地址    
  卡片对应位置: 左侧圆形头像                              
  ────────────────────────────────────────
  字段: gender                                            
  类型: string                                            
  可空: 是                                     
  说明: 性别枚举 MALE / FEMALE（可能为 null）             
  卡片对应位置: 卡片装饰（可选）                        
  ────────────────────────────────────────                
  字段: specialty
  类型: string                                            
  可空: 是                                              
  说明: 专长（长文本，旧字段，展示时优先用 specialtyTags）
  卡片对应位置: ⚠️ 已被 specialtyTags 取代，保留向后兼容
  ────────────────────────────────────────
  字段: hospitalName                     
  类型: string               
  可空: 是                  
  说明: 所属医院名称                
  卡片对应位置: 视需求展示                  
  ────────────────────────────────────────
  字段: departmentName                   
  类型: string                                            
  可空: 是                  
  说明: 科室名称（如"眼底病科"）                          
  卡片对应位置: 职称右侧                                
  ────────────────────────────────────────     
  字段: consultationRoom                 
  类型: string                                            
  可空: 是                  
  说明: 诊室编号                                          
  卡片对应位置: 视需求展示                              
  ────────────────────────────────────────     
  字段: keyVersion                       
  类型: int                                               
  可空: 否                  
  说明: E2EE 公钥版本，发起会话时需要                     
  卡片对应位置: 对接 E2EE 加密流程                      
  ────────────────────────────────────────     
  字段: specialtyTags                    
  类型: string[]                                          
  可空: 否（永远返回数组，空时 []）
  说明: 擅长方向标签数组（≥0 个）                         
  卡片对应位置: 指标下方的 tag 列表                     
  ────────────────────────────────────────     
  字段: bio                                             
  类型: string                                            
  可空: 是                  
  说明: 医生简介（长文本，约 50-150 字）                  
  卡片对应位置: 卡片底部灰色段落                        
  ────────────────────────────────────────     
  字段: rating                                          
  类型: number                                            
  可空: 是                  
  说明: 评分，0.0 - 5.0，一位小数                         
  卡片对应位置: ⭐ 图标 + 数字              D            
  ────────────────────────────────────────     
  字段: consultationCount                               
  类型: int                                               
  可空: 是                  
  说明: 累计接诊人次                                      
  卡片对应位置: 🔄 图标 + 数字（"X评") "X评"            
  ────────────────────────────────────────     
  字段: yearsOfExperience                               
  类型: int                                               
  可空: 是                  
  说明: 从业年限（年数）                                  
  卡片对应位置: 🎓 图标 + "XX年从业年限"

  ┌──────────┬─────┬───────┬───────────────┬──────────┐   
  │   场景   │ HTT │ code  │      msg      │ 处理建议 │ 
  │          │  P  │       │               │          │
  ├──────────┼─────┼───────┼───────────────┼──────────┤
  │ 未登录 / │     │ Sa-To │ not token /   │          │
  │  Token   │ 401 │ ken   │ token timeout │ 跳转登录 │
  │ 失效     │     │ 默认  │               │          │
  ├──────────┼─────┼───────┼───────────────┼──────────┤
  │ 参数异常 │     │       │ 服务端会自动  │          │   
  │ （如     │ 200 │ 200   │ 修正 page≥1、 │ 无需处理 │
  │ page     │     │       │ size∈[1,100]  │          │   
  │ 为负）   │     │       │               │          │ 
  ├──────────┼─────┼───────┼───────────────┼──────────┤

  6. 前端对接要点（重要）                                 
                                         
  1. "在线"徽章由前端自渲染：列表中能出现的医生即默认在线 
  ，不依赖后端字段。                                      
  2. specialtyTags 永远是数组：空标签会返回 []，前端可直接
   .map() 无需判空；建议最多展示前 3 个 tag。             
  3. 数值字段可能为 null：rating / consultationCount /  
  yearsOfExperience / title / avatarUrl / bio 等均允许为
  null，需做占位：                                        
    - rating == null → 不展示星标或显示"暂无评分"
    - consultationCount == null → 隐藏该指标项            
    - yearsOfExperience == null → 隐藏该指标项          
    - avatarUrl == null → 使用默认头像占位                
  4. specialty vs specialtyTags：旧字段 specialty       
  请勿再用于展示；卡片 tag 区统一改用                     
  specialtyTags。specialty 保留仅为向后兼容。           
  5. 评分精度：rating 为小数，建议前端 toFixed(1)         
  显示（例如后端 4.9 → 4.9；若返回 5 → 5.0）。            
  6. 卡片按钮"图文咨询/视频问诊"：是前端动作按钮，不依赖该
  接口返回字段；点击后按 doctorId + keyVersion 走 POST    
  /api/app/chat/sessions 创建会话。                       
  7. 头像 URL 类型：目前返回完整 http(s) URL，前端可直接  
  <img src=...>，无需拼接前缀。                           
                                                          
  ---                                                     
  7. 后续扩展提示（可忽略）                    
                                                          
  - rating / consultationCount / yearsOfExperience      
  目前是演示字段，未来会切换到真实聚合（评价表/会话表/执业
  许可），字段名与类型不会变，前端无需调整。              
  - 若未来增加标签筛选、排序等能力，会新增 Query 参数（如
  tag=近视激光矫正），不会破坏现有签名。
