# 健康资讯功能说明文档

## 📱 功能概述

健康资讯模块是AI医问通的核心内容板块，提供专业、权威的医疗健康资讯，包含眼科、内科、外科、养生保健等多个分类。

## ✨ 核心特性

### 1. 列表页功能

#### 🔍 搜索功能
- **实时搜索**：支持标题、关键词、标签搜索
- **搜索防抖**：输入停止500ms后自动触发搜索
- **热门标签**：一键快速搜索常见健康话题
- **搜索结果**：高亮匹配内容，空状态友好提示

#### 📑 分类筛选
- **多分类支持**：全部、眼科、内科、外科、养生保健、营养膳食、心理健康
- **横向滚动**：分类Tab可左右滑动浏览
- **指示器动画**：选中分类有下划线滑动动画
- **自动居中**：切换分类时自动滚动到合适位置

#### 🔄 下拉刷新
- **原生支持**：使用uni-app的refresher组件
- **视觉反馈**：下拉时显示加载动画
- **数据更新**：刷新后获取最新资讯

#### 📄 上拉加载
- **自动加载**：滚动到底部自动加载下一页
- **加载状态**：显示"加载中"、"上拉加载更多"、"已经到底了"
- **防重复**：加载中禁止重复触发

#### 🎨 资讯卡片
- **大图模式**：封面图 + 标题 + 摘要 + 元信息
- **无图模式**：纯文本展示，适合快速阅读
- **分类标签**：不同分类使用不同颜色标识
- **元信息**：来源、时间、阅读量
- **点击动画**：按下缩放效果

#### 💀 骨架屏
- **首次加载**：显示5个骨架卡片
- **闪烁动画**：渐变移动效果
- **流畅体验**：避免白屏等待

### 2. 详情页功能

#### 📰 内容展示
- **富文本渲染**：支持标题、段落、列表、引用、图片、表格
- **文章头部**：
  - 标题（大字号、加粗）
  - 元信息（来源、作者、发布时间、阅读量、点赞数）
  - 标签列表（可点击筛选同类文章）
- **正文区域**：
  - H2/H3/H4 标题样式优化
  - 段落间距合理
  - 引用块特殊样式
  - 图片全宽显示，圆角处理
  - 列表缩进清晰
  - 表格适配

#### 🖼️ 图片查看
- **点击放大**：富文本中的图片可点击预览
- **uni预览**：使用uni.previewImage原生体验
- **手势缩放**：支持双指缩放、拖动

#### 💖 互动功能
- **点赞**：
  - 点击切换点赞状态
  - 心跳动画效果
  - 实时更新点赞数
- **收藏**：
  - 本地持久化存储
  - 星星闪烁动画
  - 导航栏和底部双入口
- **分享**：
  - 调用uni.showShareMenu
  - 分享标题、路径自动生成
  - 降级方案提示

#### 📊 阅读体验
- **阅读进度条**：顶部显示阅读百分比
- **智能导航栏**：
  - 初始透明隐藏
  - 滚动超过100px渐显
  - 毛玻璃背景效果
- **返回顶部**：
  - 滚动超过500px显示
  - 悬浮按钮，点击平滑回顶
- **阅读历史**：自动记录已读文章

#### 🔗 相关推荐
- **智能推荐**：同分类相关文章
- **推荐数量**：默认3篇
- **快速跳转**：点击直接打开

### 3. 状态管理

#### 💾 本地存储
- **收藏列表**：`news_favorites`
  - 存储新闻ID数组
  - 最新收藏在前
  - 实时同步状态
- **阅读历史**：`news_history`
  - 记录ID、标题、时间
  - 最多保存100条
  - 自动去重（移除旧记录）
- **数据缓存**：`news_cache`
  - 缓存列表数据
  - 默认5分钟过期
  - 减少网络请求

#### 🔄 状态同步
- 收藏状态全局同步
- 详情页返回列表页自动更新
- 点赞数实时更新

### 4. API接口

#### 📡 模拟数据
当前使用模拟数据，包含8篇精心编写的健康资讯：
1. 秋冬季节如何预防流感？
2. 每天喝多少水才健康？
3. 近视手术全攻略
4. 干眼症预防与治疗
5. 高血压患者的饮食禁忌
6. 运动健身指南
7. 糖尿病前期如何逆转？
8. 失眠怎么办？

#### 🔌 接口设计
所有接口已预留真实API对接注释，只需：
1. 打开 `utils/api/news.js`
2. 找到对应函数的 `TODO` 注释
3. 取消注释真实API调用
4. 注释或删除模拟数据代码

接口列表：
- `getNewsList(params)` - 获取列表
- `getNewsDetail(id)` - 获取详情
- `getCategories()` - 获取分类
- `getHotTags()` - 获取热门标签
- `toggleFavorite(id)` - 切换收藏
- `toggleLike(id)` - 切换点赞
- `getRelatedNews(id, limit)` - 获取相关推荐
- `recordReadHistory(id)` - 记录阅读历史

## 🚀 使用指南

### 从首页进入
```javascript
// 首页已集成，点击"健康资讯"的"更多"按钮
goToNews() {
  uni.navigateTo({
    url: '/pages/news/news-list'
  })
}

// 点击资讯卡片
goToNewsDetail(item) {
  uni.navigateTo({
    url: `/pages/news/news-detail?id=${item.id}`
  })
}
```

### 直接跳转
```javascript
// 跳转到列表页
uni.navigateTo({
  url: '/pages/news/news-list'
})

// 跳转到详情页（需要传入资讯ID）
uni.navigateTo({
  url: '/pages/news/news-detail?id=1'
})
```

### 状态管理使用
```javascript
import { isFavorite, toggleFavorite, addHistory } from '@/store/news.js'

// 检查是否已收藏
const favorited = isFavorite(newsId)

// 切换收藏状态
const newStatus = toggleFavorite(newsId)

// 添加阅读历史
addHistory(newsId, '文章标题')
```
